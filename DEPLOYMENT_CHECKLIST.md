## 🆘 Troubleshooting

### If website doesn't load:
1. Check GitHub Pages is enabled in Settings
2. Verify repository is public
3. Confirm main branch is selected
4. Wait 5-10 minutes (deployment takes time)
5. Check GitHub Pages status in Settings

### If styling looks broken:
1. Verify `styles.css` is uploaded
2. Check file path is correct
3. Clear browser cache (Ctrl+F5)
4. Check CSS link in HTML `<head>`

### If links don't work:
1. Verify file names match exactly (case-sensitive)
2. Check all href attributes
3. Ensure files are in correct location
4. Test locally first
